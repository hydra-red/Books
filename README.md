# Books

This is a Mern Stack Project. I created this project to understand **How Frontend and Backend works**.


## Features
- Create your books list 
- Delete your book
- Update you book data

![Home Page](../Screenshot%202026-11-18%20191852.png)

## Installation 
1. Clone the repo : `git clone https://github.com/hydra-red/Books.git`
2. Go to the reposotory : `cd Books`
3. Install Dependencies : `npm run built`
4. Create you .env file in server directory
5. Your .env should contain all the given in .env.example in server directory
6. Just run command in Books repo: `npm run start` 

### .env 

``` 
# port
PORT=your_port

# database
MONGODB_URI=your_MongoDB_Atlas_URI

#rate limited urls
UPSTASH_REDIS_REST_URL=your_UpStash_Redis_URL
UPSTASH_REDIS_REST_TOKEN=your_UpStash_Redis_Token 

```
